# Hospital Management System Database
## Overview

This project is a relational Hospital Management System database developed using MySQL. It models essential hospital operations, including patient management, doctors, departments, appointments, medical records, admissions, billing, and payments.

The project demonstrates relational database design, SQL querying, data manipulation, and database optimization.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## Database Structure

The database consists of eight main tables:

1. Patient
2. Doctor
3. Department
4. Appointment
5. MedicalRecord
6. Admission
7. Billing
8. Payment

## Key Features

- Relational database design
- Primary and foreign key constraints
- Sample data insertion
- Complex SQL queries and joins
- Aggregate functions and subqueries
- Common Table Expressions (CTEs)
- Window functions
- Views
- Stored procedures
- Triggers
- Temporary tables
- Database indexing

## How to Run

1. Install MySQL 8.0 or later.
2. Open MySQL Workbench.
3. Execute the SQL scripts in the following order:

   - `01_create_tables.sql`
   - `02_insert_sample_data.sql`
   - `03_analytical_queries.sql`
   - `04_advanced_features.sql`
   - `05_indexes.sql`
